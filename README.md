I work where procurement, engineering and data meet: structuring complex supplier information so that sourcing decisions can be made on evidence, and their impact can be measured.

Production engineer with about four years in aerospace procurement and supplier management. I build portfolio projects that turn real sourcing problems into working tools, using synthetic data only.

### ⚙️ How I work

**Signal → Structure → Decision → Impact.** Every project starts from a business question, organizes the data that answers it, shows the decision it supports and states what changed. AI handles the repetitive work; calculations stay deterministic and every recommendation shows its reasoning.
